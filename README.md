# 🍱Cella Box
O Cella Box é o aplicativo oficial da Cella Box Charcuterie, desenvolvido para facilitar o acesso aos produtos e experiências gastronômicas oferecidos pela marca.
Por meio do aplicativo, os clientes podem visualizar o catálogo de boxes de charcutaria.

# 📚Funcionalidades
- Visualização de matérias primas;
- Custos mensais;
- Ficha técnica de cada produto;
- Cadastro de produtos e embalagens;
- Cadastro de clientes;
- Gerar gráficos mensais e anuais;
- Lucros individuais de cada produto.
